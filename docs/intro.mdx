# 2. 考研数学

本站数学资料目前主要分为三套：

1. **数学真题**：优先级最高，用于研究真实考研命题。
2. **李正元练习题**：适合按教材章节系统训练。
3. **张宇1000题**：适合强化刷题、补充题型和提高综合能力。

如果目标是分析“考研会怎么考”，应优先阅读 **数学真题**，再使用两套练习题补充。

---

## 2.1 数学真题

数学真题按照知识模块整理，而不是简单按照年份排列。

这种结构特别适合研究：

* 某个知识点历年考过什么
* 某种题型出现频率
* 同一知识点有哪些不同命题方式
* 真题难度如何变化
* 某个方法可以解决哪些题型

### 高等数学 · 模块 1～7

[进入高数模块 1～7](/docs/数学真题/01-高数1-7/01-模块一极限的概念、性质及计算/01-一、函数极限的计算/01-小题·函数的性质及运算等3类/)

包含：

1. **模块一：极限的概念、性质及计算**
2. **模块二：极限的应用**
3. **模块三：导数的计算**
4. **模块四：导数的应用**
5. **模块五：不定积分的计算**
6. **模块六：定积分的概念、性质及计算**
7. **模块七：定积分的应用**

其中模块内部还会继续按照具体题型细分。

例如“极限”并不是单独一个页面，而会继续划分为：

> 函数极限 → 数列极限 → 无穷小比较 → 极限性质 → 各种具体计算题型

因此，如果正在研究某个具体问题，应继续沿左侧目录进入对应题型。

### 线性代数真题

[进入线性代数真题](/docs/数学真题/04-线性代数/01-模块一-行列式/01-一、低阶数值型行列式的计算/)

共分为 8 个模块：

1. **行列式**
2. **矩阵**
3. **秩**
4. **向量**
5. **线性方程组**
6. **特征值与特征向量**
7. **相似与相似对角化**
8. **二次型**

线性代数各模块关联非常紧密。

例如：

> 秩 → 向量 → 线性方程组 → 特征值 → 相似对角化 → 二次型

分析综合题时，不应只阅读单一模块，还应关注这些知识之间的联系。

然后再进入：

> 408模拟选择题

> → 存储系统

补充训练。

推荐阅读路径：

> 408真题
> → 操作系统
> → 进程管理

应优先分析真题，再使用模拟题补充。

---

## 5.4 真题优先原则

当目标是总结考研题型、命题规律、考频、重点或预测未来考法时，资料优先级建议为：

> **真题 > 高质量练习题 > 模拟题 > 自拟拓展题**

真题用于确认：

* 是否真实考过
* 考查频率
* 常见设问方式
* 难度变化
* 知识点组合方式

练习题和模拟题主要用于：

* 补充真题没有覆盖完整的题型
* 强化某种解法
* 寻找可能的变式
* 预测新的组合考法

不要因为某种题型在练习题中大量出现，就直接认为它是考研高频题型。

# 7. 推荐使用方式

如果目标是**系统学习某一章**：

> 知识点理解 → 真题 → 题型归纳 → 练习题强化 → 错题总结

如果目标是**总结某个考研题型**：

> 搜集对应模块全部真题 → 按设问方式分类 → 总结统一解法 → 用练习题验证 → 设计变式

如果目标是**快速解决一道题**：

> 判断学科 → 判断章节 → 判断知识点 → 查看同类真题 → 总结方法 → 回到原题

如果目标是**让 AI 全面研究某一知识点**，建议明确告诉 AI：

> 阅读本站对应章节的真题、练习题和模拟题；以真题为主要依据，统计并总结题型、考法、解题方法和常见陷阱，再使用练习题补充有价值的变式。

# 8. 关于本站

**To Any Docs** 是一个持续整理和扩展的个人知识库。

这里不仅保存答案，更希望把大量零散题目组织成：

> **知识点 → 题型 → 方法 → 真题 → 变式 → 总结**

对于学习者，一道题的价值不只是“把它做出来”。

更重要的是理解：

> **它属于什么题型？为什么这样做？什么条件下还能这样做？题目改变以后方法是否仍然成立？**

这也是本站组织真题、练习题和算法资料的核心目的。
