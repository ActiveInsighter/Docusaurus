# 二叉树的递归遍历

本文用二叉树的前序、中序、后序遍历，建立一套写递归代码的固定方法。以后遇到更复杂的树形递归题，也可以沿用这套思路。

:::tip[核心结论]
二叉树递归遍历只有一个框架：

1. 当前节点为空，直接返回。
2. 处理当前节点。
3. 递归处理左子树。
4. 递归处理右子树。

前序、中序、后序的区别，只是“处理当前节点”这一步放在哪里。
:::

## 1. 先理解：递归不是玄学

很多人写递归时容易卡住，是因为总想在脑子里完整模拟所有调用过程。

其实写递归时应该只关注一层：

- 当前函数负责处理当前节点。
- 左子树交给下一次递归。
- 右子树交给下一次递归。
- 当前节点为空时，本层递归结束。

也就是说，你只要写对一层，整棵树就会按照同样的规则被处理。

## 2. 递归三要素

写任何递归题，都建议按下面三个问题检查。

| 要素 | 需要回答的问题 | 在二叉树遍历中的体现 |
| --- | --- | --- |
| 递归函数的参数和返回值 | 当前递归需要哪些信息？结果要不要返回？ | 参数是当前节点 `cur` 和结果数组 `result`，通常不需要返回值 |
| 终止条件 | 什么时候不再继续递归？ | 当前节点为空：`if (cur == nullptr) return;` |
| 单层递归逻辑 | 当前这一层具体做什么？ | 处理当前节点、递归左子树、递归右子树 |

:::info
不要一上来就想“整棵树如何遍历完”。先想清楚 `traversal(cur)` 这一层应该做什么。
:::

## 3. 示例树和三种遍历顺序

下面用同一棵二叉树说明三种遍历：

对应的树结构是：

```txt
        1
      /   \
     2     3
    / \     \
   4   5     6
```

三种遍历的口诀如下：

| 遍历方式 | 顺序 | 对当前节点的处理时机 | 示例结果 |
| --- | --- | --- | --- |
| 前序遍历 | 中 → 左 → 右 | 先处理当前节点 | `1, 2, 4, 5, 3, 6` |
| 中序遍历 | 左 → 中 → 右 | 左子树结束后处理当前节点 | `4, 2, 5, 1, 3, 6` |
| 后序遍历 | 左 → 右 → 中 | 左右子树都结束后处理当前节点 | `4, 5, 2, 6, 3, 1` |

## 4. 前序遍历：中 → 左 → 右

前序遍历的特点是：**一进入当前节点，就立刻记录它**。

### 4.1 确定递归函数

因为需要把遍历结果保存到数组里，所以把结果数组作为参数传进去。

```cpp
void traversal(TreeNode* cur, vector<int>& result)
```

这里不需要返回值，因为结果通过 `result` 收集。

### 4.2 确定终止条件

当当前节点为空时，这一层没有任何事情可做，直接返回。

```cpp
if (cur == nullptr) return;
```

### 4.3 确定单层递归逻辑

前序遍历是 <span className="bt-chip">中 → 左 → 右</span>：

```cpp
result.push_back(cur->val);       // 中
traversal(cur->left, result);     // 左
traversal(cur->right, result);    // 右
```

完整代码如下：

```cpp
class Solution {
public:
    void traversal(TreeNode* cur, vector<int>& result) {
        if (cur == nullptr) return;

        result.push_back(cur->val);       // 中
        traversal(cur->left, result);     // 左
        traversal(cur->right, result);    // 右
    }

    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> result;
        traversal(root, result);
        return result;
    }
};
```

## 5. 中序遍历：左 → 中 → 右

中序遍历的特点是：**先完整处理左子树，再处理当前节点，最后处理右子树**。

```cpp
void traversal(TreeNode* cur, vector<int>& result) {
    if (cur == nullptr) return;

    traversal(cur->left, result);     // 左
    result.push_back(cur->val);       // 中
    traversal(cur->right, result);    // 右
}
```

中序遍历在二叉搜索树中非常重要，因为二叉搜索树的中序遍历结果是递增序列。

## 6. 后序遍历：左 → 右 → 中

后序遍历的特点是：**先处理完左右子树，最后处理当前节点**。

```cpp
void traversal(TreeNode* cur, vector<int>& result) {
    if (cur == nullptr) return;

    traversal(cur->left, result);     // 左
    traversal(cur->right, result);    // 右
    result.push_back(cur->val);       // 中
}
```

后序遍历很适合处理“需要先知道子树结果，再处理当前节点”的问题，例如：

- 求二叉树高度。
- 判断平衡二叉树。
- 删除树节点。
- 计算一棵子树的信息后向父节点返回。

## 7. 三种遍历的统一模板

你可以把三种写法记成一个统一模板：

```cpp
void traversal(TreeNode* cur, vector<int>& result) {
    if (cur == nullptr) return;

    // 前序位置：中
    traversal(cur->left, result);
    // 中序位置：中
    traversal(cur->right, result);
    // 后序位置：中
}
```

把 `result.push_back(cur->val);` 放在不同位置，就得到不同遍历：

```cpp
// 前序：中左右
result.push_back(cur->val);
traversal(cur->left, result);
traversal(cur->right, result);

// 中序：左中右
traversal(cur->left, result);
result.push_back(cur->val);
traversal(cur->right, result);

// 后序：左右中
traversal(cur->left, result);
traversal(cur->right, result);
result.push_back(cur->val);
```

## 8. 常见错误

### 8.1 忘记终止条件

错误写法：

```cpp
void traversal(TreeNode* cur, vector<int>& result) {
    result.push_back(cur->val);
    traversal(cur->left, result);
    traversal(cur->right, result);
}
```

如果 `cur` 是空指针，访问 `cur->val` 会直接出错。所以必须先判断：

```cpp
if (cur == nullptr) return;
```

### 8.2 把“递归函数”和“主函数”混在一起

建议把递归逻辑单独写成辅助函数：

```cpp
void traversal(TreeNode* cur, vector<int>& result);
```

主函数只负责创建结果数组、调用递归、返回结果：

```cpp
vector<int> preorderTraversal(TreeNode* root) {
    vector<int> result;
    traversal(root, result);
    return result;
}
```

### 8.3 只记代码，不理解位置

前序、中序、后序不是靠背代码，而是看当前节点在递归中的处理位置：

- 先处理当前节点，就是前序。
- 左子树后处理当前节点，就是中序。
- 左右子树都结束后处理当前节点，就是后序。

## 11. 总结

二叉树递归遍历的关键不是背三份代码，而是理解这一点：

> 递归函数只负责当前节点这一层。左子树和右子树交给相同函数继续处理。

最后再记住一句：

- 前序：当前节点在前面处理。
- 中序：当前节点在中间处理。
- 后序：当前节点在最后处理。
