# 文档总览

欢迎来到 **To Any Docs**。这里用于长期整理学习笔记、考研复习资料、计算机基础、算法总结与项目实践记录。

## 主要内容

- **数学与考研复习**：高等数学、线性代数、概率统计及真题专题整理。
- **计算机基础**：数据结构、计算机组成原理、操作系统与计算机网络。
- **算法笔记**：常见算法、题型归纳、代码实现与自动生成的算法文档。
- **项目实践**：前端、后端、自动化、部署与工程化经验。

## 使用建议

1. 通过左侧目录按章节浏览。
2. 使用顶部搜索框定位关键词、公式或具体题型。
3. 在桌面端使用右侧目录快速跳转当前文章的小节。
4. 发现内容或展示问题时，可通过 GitHub 仓库提交 Issue。

## 自动化状态

仓库会自动执行类型检查、站点构建和文档生成任务。最近运行记录保存在：

- `.github/workflow-runs/build/`
- `.github/workflow-runs/update-content/`

每个目录都包含最新 Run ID、运行链接、步骤结果、日志和最近 10 次历史记录。
