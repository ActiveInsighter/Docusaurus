# 四、傅里叶级数(数一专项)
## （一）求系数

96. **【1993-12-3 分】** 设函数 $\displaystyle f(x)=\pi x+x^{2}(-\pi<x<\pi)$ 的傅里叶级数展开式为 $\displaystyle \frac{a_{0}}{2}+\sum_{n=1}^{\infty}(a_{n} \cos n x+b_{n} \sin n x)$，则其中系数 $b_{3}$ 的值为_____.

97. **【1995-12-6 分】** 将函数 $\displaystyle f(x)=x-1(0  \leq x  \leq 2)$ 展成周期为4的余弦函数.

98. **【2003-1-4 分】** 设 $\displaystyle x^{2}=\sum_{n=0}^{\infty} a_{n} \cos n x(-\pi \leq x \leq \pi)$，则 $a_{2}=$_____.

99. **【2008-1-11 分】** 将函数 $\displaystyle f(x)=1-x^{2}(0  \leq x  \leq \pi)$ 展开成余弦级数，并求 $\displaystyle \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n^{2}}$ 的和.

100. **【2023-1-5 分】** 设 $f(x)$ 是周期为2的周期函数，且 $\displaystyle f(x)=1-x,\ x \in[0,1]$，若 $\displaystyle f(x)=\frac{a_{0}}{2}+\sum_{n=1}^{\infty} a_{n} \cos n \pi x$，则 $\displaystyle \sum_{n=1}^{\infty} a_{2 n}=$_____.

101. **【2024-1-5 分】** 已知 $\displaystyle f(x)=1+x$，若 $\displaystyle f(x)=\frac{a_{0}}{2}+\sum_{n=1}^{\infty} a_{n} \cos n x,\ x \in[0, \pi]$，则 $\displaystyle \lim _{n \to \infty} n^{2} \sin a_{2 n-1}=$_____.

## （二）利用狄利克雷定理
102. **【1988-12-3 分】** 设 $f(x)$ 是周期为2的周期函数，它在区间 $(-1,1]$ 上的定义为 $\displaystyle f(x)=\begin{cases}2, & -1<x  \leq 0 \\ x^{3}, & 0<x  \leq 1\end{cases}$，则 $f(x)$ 的傅里叶级数在 $x=1$ 处收敛于_____.

103. **【1989-12-3 分】** 设函数 $\displaystyle f(x)=x^{2}$，$\displaystyle 0  \leq x<1$，$\displaystyle S(x)=\sum_{n=1}^{\infty} b_{n} \sin n \pi x$，$\displaystyle -\infty<x<+\infty$，其中 $\displaystyle b_{n}=2 \int_{0}^{1} f(x) \sin n\pi x dx,\ (n=1,2, \cdots)$，则 $\displaystyle S\left(-\frac{1}{2}\right)$ 等于（  ）.
A. $\displaystyle -\frac{1}{2}$
B. $\displaystyle -\frac{1}{4}$
C. $\displaystyle \frac{1}{4}$
D. $\displaystyle \frac{1}{2}$

104. **【1992-12-3 分】** 设 $\displaystyle f(x)= \begin{cases}-1, & -\pi<x  \leq 0 \\ 1+x^{2}, & 0<x  \leq \pi\end{cases}$，则其以 $2 \pi$ 为周期的傅里叶级数在点 $x=\pi$ 处收敛于_____.

105. **【1999-1-3 分】** 设 $\displaystyle f(x)= \begin{cases}x, & 0  \leq x  \leq \frac{1}{2} \\ 2-2 x, & \frac{1}{2}<x<1\end{cases}$，$\displaystyle S(x)=\frac{a_{0}}{2}+\sum_{n=1}^{\infty} a_{n} \cos n \pi x$，$\displaystyle -\infty<x<+\infty$，其中 $\displaystyle a_{n}=2 \int_{0}^{1} f(x) \cos n \pi x ~d x(n=0,1,2, \cdots)$，则 $\displaystyle S\left(-\frac{5}{2}\right)$ 等于（  ）.
A. $\displaystyle \frac{1}{2}$
B. $\displaystyle -\frac{1}{2}$
C. $\displaystyle \frac{3}{4}$
D. $\displaystyle -\frac{3}{4}$

106. **【2013-1-4 分】** 设 $\displaystyle f(x)=\left|x-\frac{1}{2}\right|$，$\displaystyle b_{n}=2 \int_{0}^{1} f(x) \sin n \pi x ~d x(n=1,2, \cdots)$.令 $\displaystyle S(x)=\sum_{n=1}^{\infty} b_{n} \sin n \pi x$，则 $\displaystyle S\left(-\frac{9}{4}\right)=$（  ）
A. $\displaystyle \frac{3}{4}$
B. $\displaystyle \frac{1}{4}$
C. $\displaystyle -\frac{1}{4}$
D. $\displaystyle -\frac{3}{4}$
