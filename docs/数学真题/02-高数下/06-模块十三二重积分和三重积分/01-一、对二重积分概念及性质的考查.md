# 一、对二重积分概念及性质的考查

1. **【1999-34-3 分】**设$\displaystyle f(x,y)$连续，且 $\displaystyle f(x, y)=x y+\iint_{D} f(u, v) d u d v$，其中 $\displaystyle D$ 是由$\displaystyle y=0,\ y=x^{2},\ x=1$ 所围区域，则$\displaystyle f(x,y)$等于( )
A. $\displaystyle xy$ &emsp;&emsp; B. $\displaystyle 2xy$ &emsp;&emsp; C. $\displaystyle xy+\dfrac18$ &emsp;&emsp; D. $\displaystyle xy+1$

2. **【2005-34-4 分】**设
$$I_{1}=\iint_{D} \cos \sqrt{x^{2}+y^{2}} d \sigma,\quad I_{2}=\iint_{D} \cos (x^{2}+y^{2}) d \sigma,\quad I_{3}=\iint_{D} \cos (x^{2}+y^{2})^{2} d \sigma$$
其中 $\displaystyle D=\{(x, y) | x^{2}+y^{2} \leq 1\}$，则( )
A. $\displaystyle I_3>I_2>I_1$ &emsp;&emsp; B. $\displaystyle I_1>I_2>I_3$
C. $\displaystyle I_2>I_1>I_3$ &emsp;&emsp; D. $\displaystyle I_3>I_1>I_2$

3. **【2009-1-4 分】**正方形$\displaystyle \{(x,y)||x|\leq 1,|y|\leq 1\}$被对角线划分为四个区域$\displaystyle D_k(k=1,2,3,4)$，$\displaystyle I_{k}=\iint_{D_{k}} y \cos x d x d y$，则$\displaystyle \max\limits_{1 \le k \le4}\{I_k\}=$( )
