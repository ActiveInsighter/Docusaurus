# 四、综合计算
## 大题
1. **【2003-1-12 分】**
$$F(t)=\dfrac{\iiint_{\Omega(t)} f\left(x^{2}+y^{2}+z^{2}\right) d v}{\iint_{D(t)} f\left(x^{2}+y^{2}\right) d \sigma},\quad G(t)=\dfrac{\iint_{D(t)} f\left(x^{2}+y^{2}\right) d \sigma}{\int_{-t}^{t} f\left(x^{2}\right) d x},$$
$\displaystyle \Omega(t):x^2+y^2+z^2\le t^2$，$\displaystyle D(t):x^2+y^2\le t^2$，$\displaystyle f>0$连续。
(1)讨论$\displaystyle F(t)$在$\displaystyle (0,+\infty)$单调性；(2)证$\displaystyle t>0,F(t)>\dfrac2\pi G(t)$。

2. **【2011-12-11 分】**$\displaystyle D:0\le x,y\le1,f_{xy}''$连续，$\displaystyle f(1,y)=f(x,1)=0,\iint_{D} f(x, y) d x d y=a$，求$\displaystyle I=\iint_{D} x y f_{x y}^{\prime \prime}(x, y) d x d y$。

3. **【2018-2-10 分】**$\displaystyle D:\begin{cases}x=t-\sin t\\y=1-\cos t\end{cases}(0\le t\le2\pi)$与$\displaystyle x$轴围成，$\displaystyle \iint_{D}(x+2 y) d x d y$。

4. **【2020-3-10 分】**$\displaystyle D=\{(x,y)|x^2+y^2\le1,y\ge0\}$，
$$f(x, y)=y \sqrt{1-x^{2}}+x \iint_{D} f(x, y) d x d y$$
求$\displaystyle \iint_{D} x f(x, y) d x d y$。
