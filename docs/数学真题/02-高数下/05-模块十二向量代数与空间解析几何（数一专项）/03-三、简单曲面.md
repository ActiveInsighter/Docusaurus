# 三、简单曲面
## 小题
1. **【1998-1-5 分】**求直线 $\displaystyle l: \dfrac{x-1}{1}=\dfrac{y}{1}=\dfrac{z-1}{-1}$ 在平面 $\displaystyle \pi: x-y+2 z-1=0$ 上的投影直线 $\displaystyle l_0$ 的方程，并求 $\displaystyle l_0$ 绕 $\displaystyle y$ 轴旋转一周后所得到的曲面方程。

## 大题
1. **【1994-12-6 分】**已知点 A 与 B 的直角坐标分别为$\displaystyle (1,0,0)$ 与$\displaystyle (0,1,1)$，线段 $\displaystyle AB$ 绕$\displaystyle z$ 轴旋转一周所成的旋转曲面为 $\displaystyle S$，求由 $\displaystyle S$ 及两平面 $\displaystyle z=0,\ z=1$ 所围成的立体体积

2. **【2009-1-11 分】**(Ⅰ)椭球面 $\displaystyle S_1$ 是椭圆 $\displaystyle \dfrac{x^{2}}{4}+\dfrac{y^{2}}{3}=1$ 绕 $\displaystyle x$ 轴旋转而成。$\displaystyle S_2$ 是由过点$\displaystyle (4,0)$ 且与该椭圆相切的直线绕 $\displaystyle x$ 轴旋转而成，求 $\displaystyle S_1$ 及 $\displaystyle S_2$ 的方程；
(Ⅱ)求 $\displaystyle S_1$ 与 $\displaystyle S_2$ 之间的立体的体积。
