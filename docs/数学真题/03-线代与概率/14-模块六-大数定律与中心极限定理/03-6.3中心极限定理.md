# 6.3 中心极限定理
## 小题
1. **【2002-4-3 分】** 设随机变量 $\displaystyle X_1, X_2, \cdots, X_n$ 相互独立, $\displaystyle S_n=X_1+X_2+\cdots+X_n$, 则根据列维-林德柏格(Levy-Lindberg) 中心极限定理, 当 n 充分大时, $\displaystyle S_n$ 近似服从正态分布, 只要 $\displaystyle X_1, X_2, \cdots, X_n$( )
A. 有相同的数学期望 &emsp;&emsp; B. 有相同的方差
C. 服从同一指数分布 &emsp;&emsp; D. 服从同一离散型分布

2. **【2005-4-5 分】** 设 $\displaystyle X_1, X_2, \cdots, X_n, \cdots$ 为独立同分布的随机变量列, 且均服从参数为 $\displaystyle \lambda(\lambda>1)$ 的指数分布, 记 $\displaystyle \Phi(x)$ 为标准正态分布函数, 则( )

A. $\displaystyle \lim_{n \to \infty}P\left\{\dfrac{\sum_{i=1}^{n}X_i-n\lambda}{\lambda\sqrt{n}} \leq x\right\}=\Phi(x)$
B. $\displaystyle \lim_{n \to \infty}P\left\{\dfrac{\sum_{i=1}^{n}X_i-n\lambda}{\sqrt{n\lambda}} \leq x\right\}=\Phi(x)$
C. $\displaystyle \lim_{n \to \infty}P\left\{\dfrac{\lambda\sum_{i=1}^{n}X_i-n}{\sqrt{n}} \leq x\right\}=\Phi(x)$
D. $\displaystyle \lim_{n \to \infty}P\left\{\dfrac{\sum_{i=1}^{n}X_i-\lambda}{\sqrt{n\lambda}} \leq x\right\}=\Phi(x)$

3. **【2020-1-4 分】** 设 $\displaystyle X_1, X_2, \cdots, X_{100}$ 为来自总体 X 的简单随机样本, 其中 $\displaystyle P\{X=0\}=P\{X=1\}=\dfrac{1}{2}$, $\displaystyle \Phi(x)$ 表示标准正态分布函数, 则利用中心极限定理可得 $\displaystyle P\left\{\sum_{i=1}^{100}X_i \leq 55\right\}$ 的近似值为( )
A. $\displaystyle 1-\Phi(1)$ &emsp;&emsp; B. $\displaystyle \Phi(1)$
C. $\displaystyle 1-\Phi(2)$ &emsp;&emsp; D. $\displaystyle \Phi(2)$

## 大题
1. **【1988-4-6 分】** 某保险公司多年的统计资料表明, 在索赔户中被盗索赔户占20%, 以 X 表示在随意抽查的100 个索赔户中因被盗向保险公司索赔的户数.
(1)写出 X 的概率分布;
(2) 利用棣莫佛-拉普拉斯定理, 求出索赔户不少于14 户且不多于30 户的概率的近似值.

2. **【1996-4-6 分】** 假设 $\displaystyle X_1, X_2, \cdots, X_n$ 是来自总体 X 的简单随机样本, 已知 $\displaystyle E(X^k)=a_k(k=1, 2, 3, 4)$ .证明: 当 n 充分大时, 随机变量 $\displaystyle Z_n=\dfrac{1}{n}\sum_{i=1}^{n}X_i^2$ 近似服从正态分布, 并指出其分布参数.

3. **【2001-34-8 分】** 一生产线生产的产品成箱包装, 每箱的重量是随机的. 假设每箱平均重50 千克, 标准差为5 千克.若用最大载重量为5 吨的汽车承运, 试利用中心极限定理说明每辆车最多可以装多少箱, 才能保障不超载的概率大于0.977. ($\displaystyle \Phi(2)=0.977$, 其中 $\displaystyle \Phi(x)$ 是标准正态分布函数)
