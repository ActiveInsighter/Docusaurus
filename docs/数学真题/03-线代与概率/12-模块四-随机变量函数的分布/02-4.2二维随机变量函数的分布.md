## 大题
1. **【1994-4-8 分】** 假设随机变量 $\displaystyle X_1$, $\displaystyle X_2$, $\displaystyle X_3$, $\displaystyle X_4$ 相互独立, 且同分布. $\displaystyle P\{X_i=0\}=0.6$, $\displaystyle P\{X_i=1\}=0.4(i=1, 2, 3, 4)$ .求行列式 $\displaystyle X=\begin{vmatrix}X_1 & X_2 \\ X_3 & X_4\end{vmatrix}$ 的概率分布.

2. **【2006-4-8 分】** 设二维随机变量 $\displaystyle (X, Y)$ 的概率分布为

| $\displaystyle X\backslash Y$ | -1  | 0   | 1   |
| --------------- | --- | --- | --- |
| -1              | a   | 0   | 0.2 |
| 0               | 0.1 | b   | 0.2 |
| 1               | 0   | 0.1 | c   |

其中 a, b, c 为常数, 且 X 的数学期望 $\displaystyle E(X)=-0.2$, $\displaystyle P\{Y \leq 0|X \leq 0\}=0.5$, 记 $\displaystyle Z=X+Y$, 求:
(1)a, b, c 的值;
(2)Z 的概率分布;
(3) $\displaystyle P\{X=Z\}$.

3. **【2018-13-11 分】** 设随机变量 X 与 Y 相互独立, X 的概率分布为 $\displaystyle P\{X=1\}=P\{X=-1\}=\dfrac{1}{2}$ . Y 服从参数为 $\displaystyle \lambda$ 的泊松分布.令 $\displaystyle Z=XY$
(I)求 $\displaystyle Cov(X, Z)$;
(II)求 Z 的概率分布.
