# 59. 螺旋矩阵 II

## 1. 题目描述

给定一个正整数 `n`，生成一个包含 `1` 到 `$n^2$` 所有元素的正方形矩阵，元素按照顺时针顺序螺旋排列。

示例：

```text
输入: n = 3
输出:
[
  [1, 2, 3],
  [8, 9, 4],
  [7, 6, 5]
]
```

## 2. 本题考察什么

这道题不涉及复杂算法，重点是模拟过程。

难点在于边界：

- 上边怎么填？
- 右边怎么填？
- 下边怎么填？
- 左边怎么填？
- 拐角是否重复？
- 奇数阶矩阵中心点怎么处理？

如果每条边的开闭规则不统一，代码很容易变成一堆特判。

:::tip[核心原则]

每一圈都按照统一规则填充。本文采用“左闭右开”的思想：每条边都填到拐角前一个位置，把拐角交给下一条边处理。

:::

## 3. 模拟顺序

每一圈按四个方向填充：

1. 上边：从左到右；
2. 右边：从上到下；
3. 下边：从右到左；
4. 左边：从下到上。

```text
第一圈:
→ → →
↑   ↓
← ← ←

第二圈继续向内收缩。
```

## 4. 变量设计

| 变量 | 含义 |
| :--- | :--- |
| `startX` | 当前圈起始行 |
| `startY` | 当前圈起始列 |
| `loop` | 需要完整填几圈，值为 `n / 2` |
| `mid` | 当 `n` 为奇数时，中心点坐标 |
| `count` | 当前要填入的数字 |
| `offset` | 控制当前圈的边界收缩 |

对于 `n = 3`：

- 完整圈数是 `1`；
- 中心点是 `(1, 1)`，最后单独填入。

对于 `n = 4`：

- 完整圈数是 `2`；
- 没有中心点需要单独处理。

## 5. C++ 代码

```cpp title="左闭右开模拟" showLineNumbers {13-27,36-38}
class Solution {
public:
    vector<vector<int>> generateMatrix(int n) {
        vector<vector<int>> res(n, vector<int>(n, 0));

        int startX = 0, startY = 0;
        int loop = n / 2;
        int mid = n / 2;
        int count = 1;
        int offset = 1;

        while (loop--) {
            int i = startX;
            int j = startY;

            for (; j < n - offset; j++) {
                res[i][j] = count++;
            }

            for (; i < n - offset; i++) {
                res[i][j] = count++;
            }

            for (; j > startY; j--) {
                res[i][j] = count++;
            }

            for (; i > startX; i--) {
                res[i][j] = count++;
            }

            startX++;
            startY++;
            offset++;
        }

        if (n % 2 == 1) {
            res[mid][mid] = count;
        }

        return res;
    }
};
```

## 6. 以 `n = 3` 为例

第一圈填充过程：

| 步骤 | 方向 | 填入位置 |
| :---: | :--- | :--- |
| 1 | 上边从左到右 | `(0,0)`, `(0,1)` |
| 2 | 右边从上到下 | `(0,2)`, `(1,2)` |
| 3 | 下边从右到左 | `(2,2)`, `(2,1)` |
| 4 | 左边从下到上 | `(2,0)`, `(1,0)` |
| 5 | 中心点 | `(1,1)` |

最终矩阵：

```text
1 2 3
8 9 4
7 6 5
```

## 7. 常见错误

### 7.1 四条边规则不统一

一会儿写左闭右闭，一会儿写左闭右开，最容易导致：

- 拐角重复填；
- 某些位置漏填；
- 偶数和奇数矩阵表现不一致。

### 7.2 忘记处理中心点

当 `n` 为奇数时，中间位置不会被完整圈覆盖，需要最后单独赋值。

### 7.3 空间复杂度的表述

结果矩阵本身必须返回，不能省略。如果不把返回值计入额外空间，额外空间复杂度是 $O(1)$；如果把结果矩阵计入空间，则是 $O(n^2)$。

## 8. 复杂度分析

- 时间复杂度：$O(n^2)$，需要填满整个矩阵；
- 额外空间复杂度：$O(1)$，不计返回矩阵；
- 返回矩阵空间：$O(n^2)$。

class Solution:
    def generateMatrix(self, n: int) -> List[List[int]]:
        res = [[0] * n for _ in range(n)]
        start_x, start_y = 0, 0
        loop, mid = n // 2, n // 2
        count = 1

        for offset in range(1, loop + 1):
            i, j = start_x, start_y

            while j < n - offset:
                res[i][j] = count
                count += 1
                j += 1

            while i < n - offset:
                res[i][j] = count
                count += 1
                i += 1

            while j > start_y:
                res[i][j] = count
                count += 1
                j -= 1

            while i > start_x:
                res[i][j] = count
                count += 1
                i -= 1

            start_x += 1
            start_y += 1

        if n % 2 == 1:
            res[mid][mid] = count

        return res

## 11. 小结

模拟题最重要的是规则统一。螺旋矩阵看似边界很多，但只要坚持每条边统一使用同一开闭规则，就能让代码简洁、稳定、少特判。
