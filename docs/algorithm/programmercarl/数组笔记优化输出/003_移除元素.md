# 27. 移除元素

## 1. 题目描述

给定一个数组 `nums` 和一个值 `val`，需要**原地**移除所有等于 `val` 的元素，并返回移除后数组的新长度。

要求：

- 不使用额外数组空间；
- 只能使用 $O(1)$ 额外空间；
- 可以改变元素顺序；
- 不需要关心新长度后面的元素。

示例：

```text
输入: nums = [3,2,2,3], val = 3
输出: 2
说明: nums 的前 2 个元素为 [2,2]
```

```text
输入: nums = [0,1,2,2,3,0,4,2], val = 2
输出: 5
说明: nums 的前 5 个元素可以是 [0,1,3,0,4]
```

## 2. 为什么不能直接删除数组元素

数组在内存中是连续的。删除中间元素时，不能像链表一样单独释放某个节点，只能通过**移动**或**覆盖**来维护新的有效区间。

```text
nums = [0, 1, 2, 2, 3, 0, 4, 2]
val  = 2

处理后前 5 个元素有效：
nums = [0, 1, 3, 0, 4, ?, ?, ?]
```

后面的 `?` 是旧数据，不属于新长度范围，不需要管。

## 3. 暴力解法

### 3.1 思路

遍历数组，如果发现 `nums[i] == val`，就把后面的元素整体向前移动一位。

```text
发现要删除的位置 i
nums[i] = nums[i + 1]
nums[i + 1] = nums[i + 2]
...
```

### 3.2 C++ 代码

```cpp title="暴力移动" showLineNumbers {8-11}
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int size = nums.size();

        for (int i = 0; i < size; i++) {
            if (nums[i] == val) {
                for (int j = i + 1; j < size; j++) {
                    nums[j - 1] = nums[j];
                }
                i--;
                size--;
            }
        }

        return size;
    }
};
```

### 3.3 复杂度

- 时间复杂度：$O(n^2)$；
- 空间复杂度：$O(1)$。

暴力法能体现数组删除的本质，但效率不高。

## 4. 快慢指针法

### 4.1 思路

使用两个指针：

| 指针 | 作用 |
| :--- | :--- |
| `fast` | 遍历原数组，寻找应该保留的元素 |
| `slow` | 指向新数组中下一个要写入的位置 |

当 `nums[fast] != val` 时，说明这个元素应该保留，于是写入 `nums[slow]`，然后 `slow` 后移。

```text
原数组: [0, 1, 2, 2, 3, 0, 4, 2]
val = 2

fast 负责向前扫描
slow 负责收集不是 2 的元素

最终有效区间: [0, 1, 3, 0, 4]
```

### 4.2 C++ 代码

```cpp title="快慢指针" showLineNumbers {5,7-9}
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int slow = 0;

        for (int fast = 0; fast < nums.size(); fast++) {
            if (nums[fast] != val) {
                nums[slow] = nums[fast];
                slow++;
            }
        }

        return slow;
    }
};
```

### 4.3 复杂度

- 时间复杂度：$O(n)$；
- 空间复杂度：$O(1)$。

:::tip[为什么快慢指针高效]

每个元素最多被 `fast` 扫描一次，符合条件时最多被写入一次，所以整体是线性复杂度。

:::

## 5. 相向双指针法

题目允许改变元素顺序，因此还可以用左右指针。

### 5.1 思路

- `left` 从左向右找等于 `val` 的位置；
- `right` 从右向左找不等于 `val` 的位置；
- 用右侧有效元素覆盖左侧要删除的元素。

这种写法减少了写入次数，但会改变相对顺序。

```cpp title="相向双指针" showLineNumbers {7-10}
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int left = 0;
        int right = nums.size() - 1;

        while (left <= right) {
            if (nums[left] == val) {
                nums[left] = nums[right];
                right--;
            } else {
                left++;
            }
        }

        return left;
    }
};
```

## 6. 两种双指针对比

| 写法 | 是否保持原相对顺序 | 特点 |
| :--- | :---: | :--- |
| 快慢指针 | 是 | 更通用，适合稳定保序 |
| 相向双指针 | 否 | 写入次数可能更少，适合不要求顺序的题 |

本题更推荐快慢指针，因为逻辑更稳定，也能迁移到“移动零”“删除重复项”等题目。

## 9. 小结

数组“删除”的本质是覆盖。快慢指针让我们在一次遍历中完成筛选和覆盖，是处理数组原地修改题的基础模板。
