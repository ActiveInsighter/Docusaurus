# 44. 开发商购买土地

## 1. 题目描述

一个城市区域被划分成 `n * m` 个连续区块，每个区块有一个权值，表示土地价值。

现在要把所有区块分给 A 公司和 B 公司，但只能采用一种切分方式：

- 横向切一刀，把若干行分给一家公司，剩余行分给另一家公司；
- 或纵向切一刀，把若干列分给一家公司，剩余列分给另一家公司。

要求两个子区域都至少包含一个区块，求两家公司土地总价值差的最小值。

示例：

```text title="输入"
3 3
1 2 3
2 1 3
1 2 3
```

```text title="输出"
0
```

一种最优切法：

```text
1 2 | 3
2 1 | 3
1 2 | 3
```

左右两部分价值相同，差值为 `0`。

数据范围：

```text
1 <= n, m <= 100
n 和 m 不同时为 1
```

## 2. 暴力思路

如果枚举一条切分线后，每次都重新遍历矩阵求两边的和，复杂度会比较高。

更好的想法是：

1. 先计算整个矩阵总和 `total`；
2. 再依次统计每个可能切分位置一侧的和 `part`；
3. 另一侧的和就是 `total - part`；
4. 差值为：

$$
|part - (total - part)| = |total - 2 \times part|
$$

## 3. 行列前缀和思想

本题不需要完整二维前缀和，只需要分别统计：

- 每一行的总和；
- 每一列的总和。

然后对行和、列和做一维前缀累加即可。

例如横向切分：

```text
第 0 行
第 1 行
-------  在这里切
第 2 行
```

如果上半部分和为 `part`，下半部分就是 `total - part`。

纵向切分同理。

## 4. 切分边界要注意

如果横向切分，切分线只能在两行之间，因此有 `n - 1` 种可能：

```text
切在第 0 行后
切在第 1 行后
...
切在第 n - 2 行后
```

不能切在最后一行之后，因为那样另一部分为空。

纵向切分同理，只能切在第 `0` 列到第 `m - 2` 列之后。

:::warning[边界修正]

循环时应避免把“切在最后一行之后”或“切在最后一列之后”当成合法方案。虽然在正权值数据下通常不会影响最小值，但从题意上看这是无效切分。

:::

## 5. C++ 代码

```cpp title="行列前缀和" showLineNumbers {17-24,29-41}
#include <iostream>
#include <vector>
#include <climits>
#include <cstdlib>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    vector<vector<int>> grid(n, vector<int>(m));
    vector<int> rowSum(n, 0);
    vector<int> colSum(m, 0);
    int total = 0;

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> grid[i][j];
            rowSum[i] += grid[i][j];
            colSum[j] += grid[i][j];
            total += grid[i][j];
        }
    }

    int result = INT_MAX;

    int part = 0;
    for (int i = 0; i < n - 1; i++) {
        part += rowSum[i];
        result = min(result, abs(total - 2 * part));
    }

    part = 0;
    for (int j = 0; j < m - 1; j++) {
        part += colSum[j];
        result = min(result, abs(total - 2 * part));
    }

    cout << result << endl;
    return 0;
}
```

## 6. 过程示例

矩阵：

```text
1 2 3
2 1 3
1 2 3
```

总和：

```text
total = 18
```

行和：

```text
rowSum = [6, 6, 6]
```

列和：

```text
colSum = [4, 5, 9]
```

枚举切分：

| 切法 | 一侧和 `part` | 差值 `|total - 2 * part|` |
| :--- | :---: | :---: |
| 第 0 行后横切 | 6 | 6 |
| 第 1 行后横切 | 12 | 6 |
| 第 0 列后竖切 | 4 | 10 |
| 第 1 列后竖切 | 9 | 0 |

最小差值为 `0`。

## 7. 优化空间

实际上不一定要保存整个矩阵。读入时直接统计 `rowSum` 和 `colSum` 即可。

```cpp title="不保存矩阵的写法" showLineNumbers {10-17}
#include <iostream>
#include <vector>
#include <climits>
#include <cstdlib>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    vector<int> rowSum(n, 0);
    vector<int> colSum(m, 0);
    int total = 0;

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            int x;
            cin >> x;
            rowSum[i] += x;
            colSum[j] += x;
            total += x;
        }
    }

    int result = INT_MAX;
    int part = 0;

    for (int i = 0; i < n - 1; i++) {
        part += rowSum[i];
        result = min(result, abs(total - 2 * part));
    }

    part = 0;
    for (int j = 0; j < m - 1; j++) {
        part += colSum[j];
        result = min(result, abs(total - 2 * part));
    }

    cout << result << endl;
    return 0;
}
```

## 8. 复杂度分析

- 时间复杂度：$O(nm + n + m)$，通常记作 $O(nm)$；
- 空间复杂度：$O(n + m)$，只保存行和列和。

## 10. 小结

这道题是前缀和思想在二维矩阵切分问题中的简化应用。真正需要枚举的是切分线，而不是每次重新遍历矩阵。提前统计行和列和后，切分差值可以快速计算。
