# 数组理论基础

数组是最基础、最常用的数据结构之一。很多数组题的思路并不复杂，真正容易出错的地方往往在：下标、边界、覆盖、移动元素和循环条件。

:::tip[核心结论]

数组是存放在**连续内存空间**上的、**相同类型数据**的集合。因为地址连续，所以数组支持通过下标进行快速访问，但插入、删除中间元素时通常需要移动或覆盖后续元素。

:::

## 1. 数组是什么

数组可以理解为一排连续摆放的格子，每个格子保存一个相同类型的数据。

以长度为 6 的整型数组为例：

```text
下标:   0    1    2    3    4    5
元素:  10   20   30   40   50   60
地址:  a   a+4  a+8 a+12 a+16 a+20
```

如果一个 `int` 占 4 字节，那么相邻两个元素的地址通常相差 4 字节。

数组有两个关键特点：

1. **下标一般从 0 开始**；
2. **元素在内存中连续存放**。

## 2. 为什么数组访问快

数组支持通过下标直接定位元素。假设数组首地址为 `base`，每个元素占 `size` 字节，那么下标为 `i` 的元素地址可以看成：

$$
address(i) = base + i \times size
$$

因此访问 `arr[i]` 不需要从头遍历，时间复杂度是 $O(1)$。

:::info[对比链表]

链表的节点不要求连续存放，访问第 $i$ 个节点通常需要从头走到第 $i$ 个节点，所以随机访问是 $O(n)$。数组正好相反：随机访问快，但中间插入和删除代价较高。

:::

## 3. 数组中的元素为什么不能“直接删除”

严格来说，普通数组中某个位置的元素不能像链表节点那样被单独释放。我们通常说的“删除数组元素”，本质上是：

- 将后面的元素整体向前移动；
- 或者用后面的元素覆盖它；
- 或者维护一个新的有效长度，忽略后面的旧值。

例如删除下标为 `2` 的元素：

```text
删除前:
下标:  0   1   2   3   4
元素:  1   2   3   4   5

把后面的元素向前覆盖:
下标:  0   1   2   3   4
元素:  1   2   4   5   5

逻辑新长度为 4，有效部分是:
[1, 2, 4, 5]
```

最后一个 `5` 还在原数组里，但它已经不属于逻辑上的新数组。

## 4. 插入和删除的复杂度

| 操作 | 说明 | 时间复杂度 |
| :--- | :--- | :---: |
| 访问 `arr[i]` | 通过下标直接定位 | $O(1)$ |
| 修改 `arr[i]` | 通过下标定位后修改 | $O(1)$ |
| 尾部插入 | 容量足够时直接放到末尾 | $O(1)$ |
| 中间插入 | 插入点后面的元素需要整体后移 | $O(n)$ |
| 中间删除 | 删除点后面的元素需要整体前移 | $O(n)$ |
| 查找某个值 | 无序数组通常要遍历 | $O(n)$ |

## 5. C++ 中 `array`、普通数组和 `vector` 的区别

| 类型 | 说明 | 长度是否可变 | 内存特点 |
| :--- | :--- | :---: | :--- |
| `int arr[10]` | C 风格数组 | 不可变 | 连续内存 |
| `std::array<int, 10>` | 固定长度数组封装 | 不可变 | 连续内存 |
| `std::vector<int>` | 动态顺序容器 | 可变 | 底层通常是连续动态数组 |

`vector` 不是传统意义上的“固定数组”，它是容器。它内部通常使用连续数组存储元素，当容量不足时，会申请更大的连续空间并搬迁原有元素。

## 6. 二维数组的内存存储

### 6.1 C++ 原生二维数组

在 C++ 中，原生二维数组例如 `int arr[2][3]` 通常是按行连续存储的：

```text
arr[0][0]  arr[0][1]  arr[0][2]  arr[1][0]  arr[1][1]  arr[1][2]
```

也就是说，它在内存中本质上还是一条连续的线，只是我们用两个下标来访问。

```cpp title="C++ 二维数组地址示例" showLineNumbers
#include <iostream>
using namespace std;

int main() {
    int arr[2][3] = {
        {0, 1, 2},
        {3, 4, 5}
    };

    cout << &arr[0][0] << " " << &arr[0][1] << " " << &arr[0][2] << endl;
    cout << &arr[1][0] << " " << &arr[1][1] << " " << &arr[1][2] << endl;
}
```

如果相邻地址相差 4，说明每个 `int` 占 4 字节。

:::warning[注意]

`int arr[2][3]` 是连续的；但 `vector<vector<int>>` 不一定整体连续，因为每一行都是一个独立的 `vector`。

:::

### 6.2 Java 二维数组

Java 中的 `int[][]` 更像是“数组的数组”。例如：

```java
int[][] arr = new int[3][4];
```

可以理解为：外层数组保存 3 个引用，每个引用指向一个长度为 4 的 `int[]`。

```text
arr
 ├── arr[0] -> [0, 0, 0, 0]
 ├── arr[1] -> [0, 0, 0, 0]
 └── arr[2] -> [0, 0, 0, 0]
```

每一行内部是连续的，但不保证所有行在内存中首尾相连。

## 7. 数组题常见思想

数组章节里经常出现这些方法：

| 方法 | 典型场景 | 关键点 |
| :--- | :--- | :--- |
| 二分查找 | 有序数组中查找目标 | 明确区间定义，保持循环不变量 |
| 双指针 | 原地修改、删除、合并、反转 | 一个指针遍历，一个指针维护结果位置 |
| 滑动窗口 | 连续子数组或子串问题 | 动态维护窗口左右边界 |
| 前缀和 | 多次区间和查询 | 预处理后 $O(1)$ 查询 |
| 模拟 | 按规则填表、旋转、移动 | 统一边界规则，减少特判 |

## 8. 本章学习重点

数组题不只是“会遍历”就够了，更重要的是建立以下意识：

- 看到有序数组，优先想二分；
- 看到原地删除、移动、覆盖，优先想双指针；
- 看到连续区间、最短或最长子数组，优先想滑动窗口；
- 看到大量区间查询，优先想前缀和；
- 看到方向移动、螺旋、旋转，优先想模拟，并统一边界规则。

:::tip[一句话总结]

数组的优势是随机访问快；数组的难点是边界和移动。写数组题时，先确定下标含义和区间范围，再写循环。

:::
