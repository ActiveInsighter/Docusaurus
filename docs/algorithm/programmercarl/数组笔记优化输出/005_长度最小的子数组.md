# 209. 长度最小的子数组

## 1. 题目描述

给定一个含有 `n` 个正整数的数组 `nums` 和一个正整数 `target`，找出满足和大于等于 `target` 的长度最小的**连续子数组**，并返回它的长度。如果不存在符合条件的子数组，返回 `0`。

示例：

```text
输入: target = 7, nums = [2,3,1,2,4,3]
输出: 2
解释: 子数组 [4,3] 的和为 7，长度最小。
```

## 2. 暴力解法

### 2.1 思路

枚举每个起点 `i`，再枚举终点 `j`，不断累加 `nums[i]` 到 `nums[j]` 的和。

一旦当前和 `sum >= target`，说明找到了一个符合条件的连续子数组，可以更新最短长度。

```cpp title="暴力枚举" showLineNumbers {7-14}
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int result = INT_MAX;

        for (int i = 0; i < nums.size(); i++) {
            int sum = 0;
            for (int j = i; j < nums.size(); j++) {
                sum += nums[j];
                if (sum >= target) {
                    result = min(result, j - i + 1);
                    break;
                }
            }
        }

        return result == INT_MAX ? 0 : result;
    }
};
```

### 2.2 复杂度

- 时间复杂度：$O(n^2)$；
- 空间复杂度：$O(1)$。

暴力法会重复计算大量区间和，在数据量较大时容易超时。

## 3. 滑动窗口

### 3.1 什么是滑动窗口

滑动窗口可以理解为数组上的一段连续区间：

```text
nums = [2, 3, 1, 2, 4, 3]
           [------]
            窗口
```

本题中窗口表示一个连续子数组，我们需要动态调整窗口的左右边界，使窗口和满足条件，并尽可能短。

### 3.2 为什么可以用滑动窗口

本题数组元素都是正整数。

这意味着：

- 右边界右移，窗口和一定增加；
- 左边界右移，窗口和一定减少。

因此，当窗口和已经大于等于 `target` 时，可以放心尝试收缩左边界，看看能否得到更短的合法窗口。

:::warning[适用条件]

这个模板依赖“数组元素为正数”。如果数组中有负数，窗口和不再单调变化，普通滑动窗口就可能失效。

:::

## 4. 三个关键问题

写滑动窗口时，先回答三个问题：

| 问题 | 本题答案 |
| :--- | :--- |
| 窗口内是什么？ | 当前连续子数组 |
| 右边界如何移动？ | `right` 每次向右扩展一个元素 |
| 左边界如何移动？ | 当 `sum >= target` 时，不断右移 `left` 来缩小窗口 |

## 5. C++ 代码

```cpp title="滑动窗口" showLineNumbers {7,10-15}
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int result = INT_MAX;
        int sum = 0;
        int left = 0;

        for (int right = 0; right < nums.size(); right++) {
            sum += nums[right];

            while (sum >= target) {
                result = min(result, right - left + 1);
                sum -= nums[left];
                left++;
            }
        }

        return result == INT_MAX ? 0 : result;
    }
};
```

## 6. 过程示例

以 `target = 7`，`nums = [2,3,1,2,4,3]` 为例：

| 阶段 | 窗口 | 窗口和 | 操作 |
| :---: | :--- | :---: | :--- |
| 1 | `[2]` | 2 | 继续扩展 |
| 2 | `[2,3]` | 5 | 继续扩展 |
| 3 | `[2,3,1]` | 6 | 继续扩展 |
| 4 | `[2,3,1,2]` | 8 | 满足条件，更新长度并收缩 |
| 5 | `[3,1,2]` | 6 | 不满足，继续扩展 |
| 6 | `[3,1,2,4]` | 10 | 满足，收缩 |
| 7 | `[1,2,4]` | 7 | 满足，继续收缩 |
| 8 | `[2,4]` | 6 | 不满足，继续扩展 |
| 9 | `[2,4,3]` | 9 | 满足，收缩 |
| 10 | `[4,3]` | 7 | 长度为 2，得到最优 |

## 7. 为什么时间复杂度是 $O(n)$

虽然代码中有 `for` 和 `while`，但不是 $O(n^2)$。

原因是：

- 每个元素最多被右指针加入窗口一次；
- 每个元素最多被左指针移出窗口一次。

所以总操作次数不超过 $2n$，时间复杂度是 $O(n)$。

## 8. 复杂度分析

- 时间复杂度：$O(n)$；
- 空间复杂度：$O(1)$。

## 11. 小结

滑动窗口本质上是双指针思想在连续区间问题中的应用。右指针负责扩展窗口，左指针负责在满足条件后收缩窗口。只要窗口变化具有单调性，就要优先考虑滑动窗口。
