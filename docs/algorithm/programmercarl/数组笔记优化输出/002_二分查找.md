# 二分查找

[力扣题目链接](https://leetcode.cn/problems/binary-search/)

## 题目描述

给定一个 `n` 个元素、升序排列的整型数组 `nums`，以及一个目标值 `target`。请在 `nums` 中搜索 `target`：

- 如果目标值存在，返回它的下标；
- 如果目标值不存在，返回 `-1`。

示例 1：

```text
输入: nums = [-1,0,3,5,9,12], target = 9
输出: 4
解释: 9 出现在 nums 中并且下标为 4
```

示例 2：

```text
输入: nums = [-1,0,3,5,9,12], target = 2
输出: -1
解释: 2 不存在 nums 中，因此返回 -1
```

题目保证：

- `nums` 按升序排列；
- `nums` 中的元素不重复；
- `1 <= nums.length <= 10000`。

## 为什么可以用二分查找

二分查找的前提是：**查找空间具有单调性**。

本题中数组已经升序排列，所以当我们取中间位置 `mid` 时：

- 如果 `nums[mid] == target`，直接找到答案；
- 如果 `nums[mid] < target`，说明目标只可能在右半部分；
- 如果 `nums[mid] > target`，说明目标只可能在左半部分。

每比较一次，都能排除一半搜索范围，因此时间复杂度是 $O(\log n)$。

:::tip[二分查找真正难的地方]

二分的思想很简单，但边界很容易写错。关键不是背模板，而是先定义清楚查找区间，然后在整个循环中始终维护这个定义，这就是**循环不变量**。

:::

## 循环不变量：先定义区间，再写代码

常见的二分查找写法有两种：

| 写法   | 查找区间        | 右边界是否包含 | 循环条件        | 右边界更新        |
| :----- | :-------------- | :------------: | :-------------- | :---------------- |
| 写法一 | `[left, right]` |      包含      | `left <= right` | `right = mid - 1` |
| 写法二 | `[left, right)` |     不包含     | `left < right`  | `right = mid`     |

两种写法都正确，但不能混用。最常见的错误就是：区间定义是左闭右开，代码却写成左闭右闭的边界更新。

## 写法一：左闭右闭区间 `[left, right]`

左闭右闭表示：每一轮循环中，`target` 如果存在，就一定在 `[left, right]` 这个闭区间里。

因此：

- 当 `left == right` 时，区间里还有一个元素，仍然需要检查，所以循环条件是 `left <= right`；
- 当 `nums[mid] > target` 时，`mid` 位置已经确认不是答案，下一轮只需要找 `[left, mid - 1]`；
- 当 `nums[mid] < target` 时，下一轮只需要找 `[mid + 1, right]`。

:::info[待补图：左闭右闭二分过程]

建议画数组 `[1, 2, 3, 4, 7, 9, 10]`，目标值 `2`。每轮标出 `left`、`mid`、`right`，并用颜色高亮当前闭区间 `[left, right]`。

:::

```cpp title="左闭右闭区间写法" {6,10-14}
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size() - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] > target) {
                right = mid - 1;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                return mid;
            }
        }

        return -1;
    }
};
```

复杂度分析：

- 时间复杂度：$O(\log n)$；
- 空间复杂度：$O(1)$。

:::warning[为什么不是 `right = mid`]

在左闭右闭区间中，`right` 指向的位置属于下一轮要搜索的范围。如果当前 `nums[mid] > target`，那么 `mid` 已经不可能是答案，所以必须把它排除掉，写成 `right = mid - 1`。

:::

## 写法二：左闭右开区间 `[left, right)`

左闭右开表示：每一轮循环中，`target` 如果存在，就一定在 `[left, right)` 这个区间里。这里 `right` 指向的位置不属于查找范围。

因此：

- 当 `left == right` 时，区间 `[left, right)` 为空，不需要继续查找，所以循环条件是 `left < right`；
- 当 `nums[mid] > target` 时，下一轮查找 `[left, mid)`，所以写 `right = mid`；
- 当 `nums[mid] < target` 时，下一轮查找 `[mid + 1, right)`，所以写 `left = mid + 1`。

:::info[待补图：左闭右开二分过程]

建议画同一个数组 `[1, 2, 3, 4, 7, 9, 10]`，目标值 `2`。重点标出 `right` 不参与搜索，所以 `[left, right)` 右端是开区间。

:::

```cpp title="左闭右开区间写法" {5,7,11}
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size();

        while (left < right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] > target) {
                right = mid;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                return mid;
            }
        }

        return -1;
    }
};
```

复杂度分析：

- 时间复杂度：$O(\log n)$；
- 空间复杂度：$O(1)$。

## 两种写法如何选择

两种写法本质一样，建议初学阶段固定一种写法反复练习。很多人更推荐先掌握左闭右闭版本，因为它和直觉更一致：`left` 和 `right` 都是当前要查找的有效下标。

| 对比点             | 左闭右闭 `[left, right]` | 左闭右开 `[left, right)` |
| :----------------- | :----------------------- | :----------------------- |
| 初始右边界         | `nums.size() - 1`        | `nums.size()`            |
| `left == right` 时 | 区间还有一个元素         | 区间为空                 |
| 循环条件           | `left <= right`          | `left < right`           |
| 去左半区间         | `right = mid - 1`        | `right = mid`            |
| 去右半区间         | `left = mid + 1`         | `left = mid + 1`         |

## 常见错误

### 错误一：区间定义混乱

例如你初始化：

```cpp
int right = nums.size();
```

这说明你更像是在使用左闭右开区间 `[left, right)`。但如果后面又写：

```cpp
right = mid - 1;
```

就把左闭右闭和左闭右开混在一起了，很容易漏掉答案或死循环。

### 错误二：中点计算可能溢出

不推荐写：

```cpp
int mid = (left + right) / 2;
```

如果 `left` 和 `right` 都很大，`left + right` 可能溢出。更稳妥的写法是：

```cpp
int mid = left + (right - left) / 2;
```

### 错误三：循环条件想当然

`while (left <= right)` 和 `while (left < right)` 没有谁一定更正确，它们必须和区间定义配套使用。

## 本篇小结

二分查找不是只记住几行代码，而是要记住一条原则：**先定义查找区间，再根据区间定义处理边界。**

- 用 `[left, right]`，就配套使用 `left <= right` 和 `right = mid - 1`；
- 用 `[left, right)`，就配套使用 `left < right` 和 `right = mid`；
- `mid` 建议写成 `left + (right - left) / 2`，避免潜在溢出；
- 只要区间定义不乱，二分查找的边界问题就会清晰很多。
