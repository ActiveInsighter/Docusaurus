# 数组总结篇

数组是算法学习中最基础的一类数据结构。它的题目往往不难理解，但很考验代码实现能力，尤其是下标、边界、循环条件和原地修改。

## 1. 数组理论回顾

数组是存放在连续内存空间上的相同类型数据集合。

它的核心特点如下：

| 特点 | 说明 |
| :--- | :--- |
| 下标访问 | 可以通过下标快速访问元素 |
| 连续内存 | 元素在内存中通常连续存放 |
| 随机访问快 | 访问 `arr[i]` 是 $O(1)$ |
| 插入删除慢 | 中间插入或删除通常需要移动元素，复杂度是 $O(n)$ |
| 原地删除本质 | 普通数组不能单独删除某个元素，只能移动或覆盖 |

数组题容易出错的根源通常不是算法思想，而是边界处理。

:::tip[数组题的第一原则]

写循环前，先确定每个变量的含义，再确定区间开闭规则。不要一边写一边补边界。

:::

## 2. 本章核心题型

本章涉及的题目可以归纳为五类：

| 类型 | 代表题目 | 核心思想 |
| :--- | :--- | :--- |
| 二分查找 | 704. 二分查找 | 有序数组中折半缩小区间 |
| 双指针 | 27. 移除元素、977. 有序数组的平方 | 用两个指针减少重复遍历 |
| 滑动窗口 | 209. 长度最小的子数组 | 动态维护连续区间 |
| 模拟 | 59. 螺旋矩阵 II | 按规则模拟过程，统一边界 |
| 前缀和 | 58. 区间和、44. 开发商购买土地 | 预处理累加信息，快速查询 |

## 3. 二分查找

二分查找适用于有序数组。

它的关键不在于“每次取中间”，而在于区间定义：

| 写法 | 区间 | 循环条件 | 右边界更新 |
| :--- | :--- | :--- | :--- |
| 左闭右闭 | `[left, right]` | `left <= right` | `right = mid - 1` |
| 左闭右开 | `[left, right)` | `left < right` | `right = mid` |

二分法最重要的思想是**循环不变量**：

> 如果目标存在，它始终在当前定义的查找区间内。

### 3.1 复杂度

- 暴力查找：$O(n)$；
- 二分查找：$O(\log n)$。

### 3.2 常见错误

- `while (left < right)` 和 `while (left <= right)` 混用；
- `right = mid` 和 `right = mid - 1` 混用；
- 没有先明确区间开闭规则。

## 4. 双指针

双指针常用于数组和链表题。

### 4.1 快慢指针

典型题目：27. 移除元素。

快慢指针的本质是：

- 快指针负责扫描原数组；
- 慢指针负责维护新数组的写入位置。

```text
fast 负责找可保留元素
slow 负责写入可保留元素
```

这样可以把原本需要两层循环的移动过程，优化成一次遍历。

### 4.2 相向双指针

典型题目：977. 有序数组的平方。

有序数组平方后，最大值只可能出现在两端，因此可以：

- 左指针指向开头；
- 右指针指向末尾；
- 每次比较两端平方，把较大值放入结果数组尾部。

### 4.3 复杂度

双指针通常可以把 $O(n^2)$ 或 $O(n \log n)$ 的写法优化到 $O(n)$。

## 5. 滑动窗口

典型题目：209. 长度最小的子数组。

滑动窗口适合处理连续子数组或连续子串问题。

它的基本结构是：

```text
右指针扩展窗口
满足条件后，左指针收缩窗口
```

写滑动窗口前要先问三个问题：

| 问题 | 作用 |
| :--- | :--- |
| 窗口内是什么？ | 明确当前维护的状态 |
| 右边界如何移动？ | 决定如何扩展窗口 |
| 左边界如何移动？ | 决定何时收缩窗口 |

### 5.1 为什么不是 $O(n^2)$

虽然滑动窗口里经常出现 `for + while`，但每个元素最多进窗口一次、出窗口一次，所以总复杂度通常是 $O(n)$。

### 5.2 适用条件

普通滑动窗口常依赖某种单调性。例如 209 题中数组元素都是正数，所以窗口右扩时和增加，左缩时和减少。

如果数组中允许负数，就要重新分析，不能机械套模板。

## 6. 模拟

典型题目：59. 螺旋矩阵 II。

模拟题不一定难，但很容易写乱。关键是统一规则。

以螺旋矩阵为例，每一圈按四个方向填：

1. 上边从左到右；
2. 右边从上到下；
3. 下边从右到左；
4. 左边从下到上。

如果每条边都用统一的左闭右开规则，就能减少重复填拐角的问题。

:::warning[模拟题常见问题]

模拟题不要靠“补丁式特判”硬调边界。应该先设计统一规则，再按规则写代码。

:::

## 7. 前缀和

前缀和适用于频繁区间求和。

推荐写法：

```text
prefix[0] = 0
prefix[i + 1] = prefix[i] + nums[i]
```

区间 `[left, right]` 的和为：

$$
sum(left, right) = prefix[right + 1] - prefix[left]
$$

### 7.1 一维前缀和

典型题目：58. 区间和。

如果有很多次查询，每次都暴力累加会很慢。前缀和预处理后，单次查询可以做到 $O(1)$。

### 7.2 二维或行列前缀思想

典型题目：44. 开发商购买土地。

这道题不一定需要完整二维前缀和，只要统计每一行、每一列的和，再枚举切分线即可。

差值公式：

$$
|total - 2 \times part|
$$

其中 `part` 是切分后一侧的总和。

## 8. 方法选择速查表

| 题目信号 | 优先考虑 |
| :--- | :--- |
| 有序数组、查找目标 | 二分查找 |
| 原地删除、移动、覆盖 | 快慢指针 |
| 两端元素有特殊性质 | 相向双指针 |
| 连续子数组、最短、最长 | 滑动窗口 |
| 多次查询区间和 | 前缀和 |
| 按规则填矩阵、旋转、移动 | 模拟 |

## 9. 复杂度对比

| 题型 | 朴素方法 | 优化方法 |
| :--- | :---: | :---: |
| 二分查找 | $O(n)$ | $O(\log n)$ |
| 移除元素 | $O(n^2)$ | $O(n)$ |
| 有序数组平方 | $O(n \log n)$ | $O(n)$ |
| 长度最小子数组 | $O(n^2)$ | $O(n)$ |
| 区间和多次查询 | $O(nm)$ | $O(n + m)$ |
| 矩阵切分 | 重复遍历较慢 | $O(nm)$ |

## 10. 学习建议

数组章节建议重点练三件事：

1. **边界意识**：区间到底是闭区间还是开区间；
2. **指针含义**：每个指针代表扫描位置、写入位置，还是窗口边界；
3. **复杂度意识**：每个元素到底被处理了几次。

## 11. 小结

数组题是后续链表、哈希表、字符串、动态规划等内容的基础。真正掌握数组，不是会写几个循环，而是能在不同题目中识别背后的模式：二分、双指针、滑动窗口、前缀和和模拟。

:::tip[最终总结]

数组的核心能力是“用下标控制状态”。只要下标含义清楚、区间规则统一，数组题就会稳定很多。

:::
