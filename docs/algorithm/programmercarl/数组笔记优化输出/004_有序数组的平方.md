# 有序数组的平方

[力扣题目链接](https://leetcode.cn/problems/squares-of-a-sorted-array/)

## 题目描述

给你一个按 **非递减顺序** 排序的整数数组 `nums`，请返回每个数字的平方组成的新数组，要求新数组也按 **非递减顺序** 排序。

:::tip[关键词]

原数组已经有序，但平方之后不一定仍然有序。问题的关键不在于“平方”，而在于如何利用原数组的有序性，避免再次完整排序。

:::

## 示例

### 示例 1

```text
输入：nums = [-4, -1, 0, 3, 10]
输出：[0, 1, 9, 16, 100]
解释：平方后得到 [16, 1, 0, 9, 100]，排序后得到 [0, 1, 9, 16, 100]
```

### 示例 2

```text
输入：nums = [-7, -3, 2, 3, 11]
输出：[4, 9, 9, 49, 121]
```

## 思路总览

这道题有两种常见做法：

| 方法     | 核心思路                               |  时间复杂度   |   空间复杂度   |
| :------- | :------------------------------------- | :-----------: | :------------: |
| 暴力排序 | 先平方，再排序                         | $O(n \log n)$ | 取决于排序实现 |
| 双指针   | 比较两端平方值，从结果数组末尾倒序填充 |    $O(n)$     |     $O(n)$     |

更推荐掌握 **双指针法**。它利用了一个非常关键的性质：

> 对于一个非递减数组，平方后的最大值只可能来自原数组的两端。

## 为什么最大平方值一定在两端？

原数组是非递减的，例如：

```text
[-7, -3, 2, 3, 11]
```

负数越小，绝对值可能越大；正数越大，绝对值也越大。平方之后比较的是绝对值大小：

```text
平方大小 = 绝对值大小的平方
```

所以当前未处理区间 `[left, right]` 中，平方最大的元素只可能是：

- `nums[left] * nums[left]`
- `nums[right] * nums[right]`

中间元素的绝对值不可能同时超过两端。因此我们可以不断比较两端，把更大的平方数放入结果数组的最后面。

:::info[图示占位]

这里后续补一张“双指针从两端向中间移动，结果数组从后往前填充”的过程图。

建议画法：上方画原数组，标出 `left`、`right`；下方画结果数组，标出 `index` 从末尾向前移动。

:::

## 方法一：暴力排序

最直观的做法是：先把每个元素平方，再对数组排序。

```cpp title="C++ 暴力排序"
class Solution {
public:
    vector<int> sortedSquares(vector<int>& nums) {
        for (int i = 0; i < nums.size(); i++) {
            nums[i] *= nums[i];
        }
        sort(nums.begin(), nums.end());
        return nums;
    }
};
```

这个方法简单，但没有充分利用“原数组有序”这一条件。

- 平方遍历需要 $O(n)$；
- 排序通常需要 $O(n \log n)$；
- 总体时间复杂度为 $O(n \log n)$。

## 方法二：双指针法

### 指针含义

设三个指针：

| 指针    | 含义                                       |
| :------ | :----------------------------------------- |
| `left`  | 指向当前未处理区间的最左端                 |
| `right` | 指向当前未处理区间的最右端                 |
| `index` | 指向结果数组当前应该填入的位置，从末尾开始 |

每次比较 `nums[left]` 和 `nums[right]` 的平方：

- 如果左端平方更大，就把它放到 `result[index]`，然后 `left++`；
- 如果右端平方更大，就把它放到 `result[index]`，然后 `right--`；
- 无论放入哪一端，`index--`。

### 为什么结果数组要从后往前填？

因为每次比较两端时，我们拿到的是当前未处理元素中的 **最大平方值**。

而最终结果要求非递减排序，最大值应该放在最后，所以结果数组要从右往左填。

```text
原数组：       [-4, -1, 0, 3, 10]
比较两端：      16           100
结果数组：     [0, 0, 0, 0, 100]
                              ↑
                            index
```

### C++ 核心代码

```cpp title="C++ 双指针" {6-17}
class Solution {
public:
    vector<int> sortedSquares(vector<int>& nums) {
        int n = nums.size();
        vector<int> result(n, 0);
        int left = 0;
        int right = n - 1;
        int index = n - 1;

        while (left <= right) {
            int leftSquare = nums[left] * nums[left];
            int rightSquare = nums[right] * nums[right];

            if (leftSquare > rightSquare) {
                result[index--] = leftSquare;
                left++;
            } else {
                result[index--] = rightSquare;
                right--;
            }
        }

        return result;
    }
};
```

:::warning[易错点]

循环条件必须是 `left <= right`，不能写成 `left < right`。

当 `left == right` 时，说明还剩最后一个元素没有放入结果数组，这个元素也必须被处理。

:::

## 复杂度分析

- 时间复杂度：$O(n)$。每个元素只会被 `left` 或 `right` 处理一次。
- 空间复杂度：$O(n)$。需要一个新的结果数组保存答案。

## 小结

这道题的核心不是“平方后排序”，而是从有序数组中观察到：**平方最大值只可能出现在当前区间的两端**。

因此我们可以用双指针不断取出当前最大平方值，并从结果数组末尾倒序填充。这样就把排序问题优化成了一次线性扫描。
