# 58. 区间和

## 1. 题目描述

给定一个整数数组 `Array`，需要计算该数组在每个指定区间内的元素总和。

输入格式：

- 第一行输入数组长度 `n`；
- 接下来 `n` 行，每行一个整数，表示数组元素；
- 随后输入若干个查询区间 `[a, b]`，直到文件结束。

输出格式：

- 对每个查询区间，输出区间内元素之和。

示例：

```text title="输入"
5
1
2
3
4
5
0 1
1 3
```

```text title="输出"
3
9
```

数据范围：

```text
0 < n <= 100000
```

## 2. 暴力解法

最直接的想法是：每次给一个区间 `[a, b]`，就从 `a` 加到 `b`。

```cpp title="暴力区间求和" showLineNumbers {9-12}
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, a, b;
    cin >> n;
    vector<int> nums(n);
    for (int i = 0; i < n; i++) cin >> nums[i];

    while (cin >> a >> b) {
        int sum = 0;
        for (int i = a; i <= b; i++) {
            sum += nums[i];
        }
        cout << sum << endl;
    }
}
```

如果有 `m` 次查询，每次查询长度接近 `n`，时间复杂度就是：

$$
O(n \times m)
$$

当查询次数很多时，这种写法会超时。

## 3. 前缀和思想

前缀和的核心是：**把从开头到某个位置的累加结果提前算好，后续区间查询直接相减。**

推荐使用长度为 `n + 1` 的前缀和数组：

```text
prefix[0] = 0
prefix[i + 1] = nums[0] + nums[1] + ... + nums[i]
```

也就是说，`prefix[i]` 表示原数组前 `i` 个元素之和。

例如：

```text
nums   = [1, 2, 3, 4, 5]
prefix = [0, 1, 3, 6, 10, 15]
```

## 4. 区间和公式

如果要求闭区间 `[left, right]` 的和，则：

$$
sum(left, right) = prefix[right + 1] - prefix[left]
$$

为什么？

```text
prefix[right + 1] = nums[0] + ... + nums[left - 1] + nums[left] + ... + nums[right]
prefix[left]      = nums[0] + ... + nums[left - 1]

两者相减，剩下 nums[left] + ... + nums[right]
```

:::tip[推荐写法]

使用 `prefix[0] = 0` 的哨兵写法，可以避免 `left == 0` 时单独判断，比 `p[i]` 表示 `[0, i]` 的写法更统一。

:::

## 5. C++ 代码

```cpp title="前缀和解法" showLineNumbers {9-12,15-16}
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> prefix(n + 1, 0);
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        prefix[i + 1] = prefix[i] + x;
    }

    int left, right;
    while (cin >> left >> right) {
        cout << prefix[right + 1] - prefix[left] << endl;
    }

    return 0;
}
```

## 6. 复杂度分析

设数组长度为 `n`，查询次数为 `m`：

| 方法 | 预处理 | 单次查询 | 总复杂度 |
| :--- | :---: | :---: | :---: |
| 暴力求和 | $O(1)$ | $O(n)$ | $O(nm)$ |
| 前缀和 | $O(n)$ | $O(1)$ | $O(n + m)$ |

前缀和适合“数组不变，多次查询区间和”的场景。

## 7. 常见错误

### 7.1 混淆 `prefix[i]` 的含义

推荐明确记住：

```text
prefix[i] 表示前 i 个元素的和，不包含 nums[i]
```

因此：

```text
nums[0] 到 nums[0] 的和 = prefix[1] - prefix[0]
nums[2] 到 nums[5] 的和 = prefix[6] - prefix[2]
```

### 7.2 忘记查询是闭区间

如果输入是 `[a, b]`，包含 `b`，就要写：

```cpp
prefix[b + 1] - prefix[a]
```

而不是：

```cpp
prefix[b] - prefix[a]
```

public class Main {

    }
}

def main():
    data = list(map(int, sys.stdin.read().split()))

        index += 2

## 9. 小结

前缀和把“每次重新累加”变成“预处理后直接相减”。只要遇到大量区间和查询，就应该优先考虑前缀和。
