<div className="choice-option-row">D. 在一条指令的执行过程中，单周期处理器的数据通路中的每个部件只能使用一次，而在多周期处理器的数据通路中同一个部件可使用多次</div>

<details>
<summary>查看答案与解析</summary>

**答案：** A

**解析：** 单周期处理器要求每条指令在一个时钟周期内完成，因此其 $\displaystyle CPI=1$。多周期处理器将一条指令拆分到多个时钟周期中完成，不同指令所需周期数可能不同，通常 $\displaystyle CPI>1$。所以“单周期处理器的 CPI 总是更大”正好相反，A 错误。

10. **【王道·卷一-Q13】** 下面是一个用来计算数组 $\displaystyle a$ 中各元素之和的程序，当参数 $\displaystyle len$ 为0时，返回值应该是0，但在执行时发生了存储器访问异常，请问程序应如何修改？（  ）。

```c
float sum_elements(float a[], unsigned len) {
int i;
float result = 0;
for(i = 0; i <= len - 1; i++)
result += a[i];
return result;
}
```

<div className="choice-options">
<div className="choice-option-row">A. 将变量result定义为double类型 &emsp;&emsp; B. 将变量result定义为int类型</div>
<div className="choice-option-row">C. 将变量len定义为int类型 &emsp;&emsp; D. 将数组 $\displaystyle a$ 定义为int类型</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** C

**解析：** 问题来自无符号整数下溢。原程序中 $\displaystyle len$ 为 `unsigned` 类型，当 $\displaystyle len=0$ 时：

$$
\displaystyle
len-1=2^w-1
$$

其中 $\displaystyle w$ 为该无符号类型的位数。结果并不是 $\displaystyle -1$，而是无符号数的最大值。比较 `i <= len - 1` 时，`i` 还会被转换为无符号数，于是循环会执行大量次数并访问数组边界之外的存储单元，最终发生存储器访问异常。

若将 $\displaystyle len$ 改为有符号 `int`，则当 $\displaystyle len=0$ 时有 $\displaystyle len-1=-1$，初始 $\displaystyle i=0$ 不满足 $\displaystyle 0\leq -1$，循环不会执行，函数正确返回 0。因此选择 C。

改变 `result` 或数组元素类型并不能消除循环边界中的无符号下溢，A、B、D 均错误。

</details>

$\displaystyle ④$ 过程返回指令 $\displaystyle ⑤$ 自陷指令 $\displaystyle ⑥$ 中断返回指令

<div className="choice-option-row">A. $\displaystyle ②③④⑤⑥$ &emsp;&emsp; B. $\displaystyle ②③⑤⑥$ &emsp;&emsp; C. $\displaystyle ①②③④⑤$ &emsp;&emsp; D. $\displaystyle ③④⑤⑥$</div>

<details>
<summary>查看答案与解析</summary>

**答案：** A

**解析：** 判断关键是区分“可能改变”与“一定改变”。

- 条件跳转指令只有在条件成立时才转移；条件不成立时仍顺序执行，因此 $\displaystyle ①$ 不一定改变程序执行顺序。

- 自陷指令会主动进入异常处理程序，$\displaystyle ⑤$ 一定改变顺序。
- 中断返回指令会恢复中断前的执行现场和返回地址，$\displaystyle ⑥$ 一定改变顺序。

因此一定改变程序执行顺序的是 $\displaystyle ②③④⑤⑥$，选择 A。

</details>

13. **【王道·卷二-Q22】** 开中断和关中断两种操作都用于对（  ）进行设置。

<div className="choice-options">
<div className="choice-option-row">A. 中断允许触发器 &emsp;&emsp; B. 中断屏蔽寄存器 &emsp;&emsp; C. 中断请求寄存器 &emsp;&emsp; D. 中断向量寄存器</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** A

**解析：** 开中断和关中断的本质，是修改 CPU 中的中断允许标志（中断允许触发器）。

- 开中断：将中断允许标志置为允许状态，使 CPU 可以响应可屏蔽中断。
- 关中断：将中断允许标志清零，使 CPU 暂时不响应可屏蔽中断。

中断屏蔽寄存器用于分别屏蔽某些中断源；中断请求寄存器记录中断请求；中断向量寄存器与中断服务程序入口定位有关。故选择 A。

</details>

14. **【王道·卷四-Q21】** 设CPU与I/O设备以中断方式进行数据传输，当CPU响应中断时，该I/O设备接口控制器送给CPU的中断向量表（中断向量表中存放中段向量）的指针是0800H，0800H单元中的值为1200H。则该I/O设备的中断服务程序在主存中的入口地址为（  ）。

<div className="choice-options">

15. **【王道·卷四-Q22】** 当下列情况出现时，引起CPU自动查询有无中断请求，进而可能进入中断响应周期的是（  ）。

<div className="choice-options">
<div className="choice-option-row">A. 一条指令执行结束 &emsp;&emsp; B. 一次I/O操作结束 &emsp;&emsp; C. 一次中断处理结束 &emsp;&emsp; D. 一次DMA操作结束</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** A

**解析：** CPU 通常在一条指令执行结束后、取下一条指令之前，统一检查是否存在满足响应条件的外部中断请求。若有未被屏蔽且优先级满足要求的请求，CPU 才进入中断响应周期。

I/O 操作结束或 DMA 操作结束可能使设备提出中断请求，但这只是“中断源提出请求”的时刻，并不等于 CPU 立即查询和响应。CPU 的自动查询时机仍是当前指令执行结束。因此选择 A。

</details>

16. **【王道·卷五-Q22】** 当外设发生异常事件或完成特定任务时，一般通过“外部中断”请求CPU执行相应的中断服务程序来处理。在以下情形中，（  ）会引起外部中断。

<div className="choice-options">
<div className="choice-option-row">A. 访问内存时缺页 &emsp;&emsp; B. Cache没有命中 &emsp;&emsp; C. 磁盘寻道结束 &emsp;&emsp; D. 运算发生溢出</div>
</div>

<details>
<summary>查看答案与解析</summary>

**解析：** 外部中断来自 CPU 当前执行指令之外的外部设备或硬件事件。磁盘寻道结束由磁盘控制器向 CPU 发出完成通知，属于典型的外部中断，因此 C 正确。

- 缺页由当前指令访问的虚拟地址无法完成转换引起，属于异常（内中断），A 错误。
- Cache 未命中由 Cache 控制器自动处理，一般不转入中断服务程序，B 错误。

## 5.6 指令流水线

### 5.6.1 指令流水线的基本概念

17. **【王道·卷六-Q19】** 在下列关于指令流水线设计的说法中，错误的是（  ）。

<div className="choice-options">
<div className="choice-option-row">A. 指令执行过程中的各个子功能都需要包含在某个流水段中</div>
<div className="choice-option-row">B. 所有子功能都必须按一定的顺序经过流水段</div>
<div className="choice-option-row">C. 虽然各子功能所用的实际时间可能不同，但经过每个流水段的时间都一样</div>
<div className="choice-option-row">D. 任何时候各个流水段的功能部件都不可能执行空（nop）操作</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** D

**解析：** 流水线将一条指令的执行过程划分为若干顺序衔接的流水段，各段在统一时钟控制下并行处理不同指令。

- 指令所需的各项子功能必须被安排到某个流水段中，A 正确。
- 指令依照设计好的流水段顺序向前推进，B 正确。
- 各段实际组合逻辑延迟可能不同，但流水线时钟周期统一，通常由最慢流水段及寄存器开销决定，因此每段占用一个相同长度的时钟周期，C 正确。
- 遇到数据冒险、控制冒险、结构冒险或流水线排空时，会在某些流水段中插入气泡，即执行 nop 操作，所以 D 错误。

</details>

### 5.6.2 流水线的基本实现

18. **【王道·卷一-Q17】** 在一个五段式指令流水线的CPU中，当执行lw指令（从内存中取数据）或sw指令（往内存中写数据）时，TLB缺失和Cache缺失有可能在（  ）时钟周期被检测到。
$\displaystyle ①$ IF(取指) $\displaystyle ②$ ID(译码/取数) $\displaystyle ③$ EX(执行) $\displaystyle ④$ Mem(存储器访问) $\displaystyle ⑤$ WB(写回)

<div className="choice-options">
<div className="choice-option-row">A. $\displaystyle ①$ 和 $\displaystyle ②$ &emsp;&emsp; B. $\displaystyle ①$ 和 $\displaystyle ④$ &emsp;&emsp; C. $\displaystyle ②$、$\displaystyle ④$ 和 $\displaystyle ⑤$ &emsp;&emsp; D. $\displaystyle ①$、$\displaystyle ④$ 和 $\displaystyle ⑤$</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** B

**解析：** `lw` 和 `sw` 都可能在两个阶段访问存储系统：

1. IF 阶段需要根据 PC 取机器指令，因此可能访问指令 TLB 和指令 Cache，此时可能检测到 TLB 缺失或 Cache 缺失。
2. Mem 阶段需要访问数据存储器，因此可能访问数据 TLB 和数据 Cache，此时也可能检测到相应缺失。

ID 阶段主要完成译码和寄存器读取，EX 阶段计算有效地址，WB 阶段完成寄存器写回，通常不会首次检测 TLB 或 Cache 缺失。因此选择 $\displaystyle ①$ 和 $\displaystyle ④$，即 B。

</details>

### 5.6.4 流水线的冒险与处理

19. **【王道·卷四-Q19】** 下面是一段指令序列：

```
add eax,20 //eax ← eax + 20
shl ecx,1 //ecx ← ecx<<1
mov edx,ecx //edx ← ecx
```

在以上指令序列中，第三条指令发生数据相关问题。假定采用“取指、译码/取数、执行、访存、写回”这种五段流水线方式。假定不采用“转发”，那么为了使这段程序的执行不被阻塞，需要在第三条指令前加入（  ）条nop指令（空操作）。

<div className="choice-options">
<div className="choice-option-row">A. 1 &emsp;&emsp; B. 2 &emsp;&emsp; C. 3 &emsp;&emsp; D. 4</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** B

**解析：** 第三条指令 `mov edx,ecx` 需要读取第二条指令 `shl ecx,1` 产生的新 `ecx` 值，二者存在写后读（RAW）数据相关。

在五段流水线中，第二条指令的执行时序为：

| 时钟周期 | 1   | 2   | 3   | 4   | 5   |
| -------- | --- | --- | --- | --- | --- |
| `shl`    | IF  | ID  | EX  | MEM | WB  |

不采用转发时，第三条指令必须等到第二条指令在 WB 阶段将结果写回寄存器后，才能在 ID 阶段正确读出该值。通常约定同一时钟周期内先写寄存器、后读寄存器，因此第三条指令的 ID 阶段可以与第二条指令的 WB 阶段处于同一周期。

若在第三条指令前插入 2 条 `nop`，则第三条指令的 ID 阶段被推迟到第二条指令的 WB 周期，数据冒险消除。因此选择 B。

</details>

### 5.6.5 高级流水线技术

20. **【王道·卷六-Q21】** 在下列关于超标量技术的描述中，错误的是（  ）。

<div className="choice-options">
<div className="choice-option-row">A. 超标量技术是指在流水线中采用更多的流水段数</div>
<div className="choice-option-row">B. 超标量技术执行指令时，可以同时发射多条指令至流水线中</div>
<div className="choice-option-row">C. 采用超标量技术的CPU必须配置多个不同的功能部件</div>

## 5.7 多处理器的基本概念

### 5.7.2 硬件多线程的基本概念

21. **【王道·卷五-Q20】** 硬件多线程技术是一种共享单个处理器核内功能部件的技术，在下列关于硬件多线程的描述中，错误的是（  ）。

<div className="choice-options">
<div className="choice-option-row">A. 每个线程实际上相当于一个指令序列 &emsp;&emsp; B. 多个线程可共享处理器核内的通用寄存器组和PC</div>

</div>

<details>
<summary>查看答案与解析</summary>

**答案：** B

**解析：** 硬件多线程通过在一个处理器核中保存多个线程的体系结构状态，使多个线程共享执行部件、流水线、Cache 等资源。为了使每个线程能够独立继续执行，每个线程必须拥有独立的程序计数器 PC 和独立的体系结构寄存器状态，因此不能共享同一套通用寄存器组和 PC，B 错误。

</details>

### 5.7.4 共享内存多处理器的基本概念

22. **【王道·卷二-Q20】** 下列关于多处理器系统的描述中，错误的是（  ）。

<div className="choice-options">
<div className="choice-option-row">A. 多处理器系统是共享存储多处理器系统的简称</div>
<div className="choice-option-row">B. 多处理器系统中所有主存储器都属于单一地址空间</div>
<div className="choice-option-row">C. 多处理器系统必须解决共享存储器的同步控制问题</div>
<div className="choice-option-row">D. 多处理器系统中各处理器对所有存储单元的访问时间是一致的</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** D

**解析：** 共享内存多处理器系统向各处理器提供统一的共享地址空间，处理器之间通过共享存储器交换数据，因此需要解决互斥、同步和 Cache 一致性等问题，A、B、C 均正确。

多处理器系统既可能采用统一存储访问结构（UMA），也可能采用非统一存储访问结构（NUMA）。在 NUMA 系统中，处理器访问本地存储器和远程存储器的时间不同，因此不能认为各处理器访问所有存储单元的时间都一致，D 错误。

</details>
