<details>

**答案：** B

**解析：** A 错误。DNS 的作用是把域名解析为 IP 地址。若已经知道目标站点的 IP 地址，仍可直接使用 IP 地址进行网络通信，不必经过域名解析。

## 6.3 文件传输协议

### 6.3.1 FTP的工作原理

2. **【王道·卷七-Q40】** 某同学利用校园网访问因特网，在从该同学打开计算机电源到使用命令ftp连通到文件服务器202.38.70.25的过程中，（  ）协议可能未用到。

<div className="choice-options">
<div className="choice-option-row">A. IP &emsp;&emsp; B. ICMP &emsp;&emsp; C. ARP &emsp;&emsp; D. DHCP</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** B

**解析：** IP 是主机在互联网中传送分组的基础协议，连接远程 FTP 服务器必须使用，A 不选。

主机通常需要通过 ARP 获得默认网关或同一局域网目标的 MAC 地址，因此 ARP 通常会被使用，C 不选。

主机开机接入校园网时，可能通过 DHCP 自动获取 IP 地址、子网掩码、默认网关等网络参数，因此 DHCP 也可能被使用，D 不选。

ICMP 主要用于差错报告和网络探测。若整个连接过程正常，且用户没有执行 `ping` 等诊断操作，则可以完全不产生 ICMP 报文。因此“可能未用到”的是 ICMP，选择 B。

## 6.5 万维网

### 6.5.2 超文本传输协议

3. **【王道·卷五-Q40】** 在下列关于客户端/服务器模型的描述中，错误的是（  ）。
I. 客户端和服务器必须都事先知道对方的地址，以提供请求和服务
II. HTTP基于客户端/服务器模型，客户端和服务器端的默认端口号都是80
III. 浏览器显示的内容来自服务器
IV. 客户端是请求方，即使连接建立后，服务器端也不能主动发送数据

<div className="choice-options">
<div className="choice-option-row">A. I和IV &emsp;&emsp; B. II和IV &emsp;&emsp; C. I、II和IV &emsp;&emsp; D. 只有IV</div>
</div>

<details>
<summary>查看答案与解析</summary>

**答案：** C

**解析：** I 错误。客户端在发起连接前必须知道服务器的地址和服务端口，但服务器无须预先知道某个具体客户端的地址；客户端连接到达后，服务器即可从连接信息中获知对端地址。

II 错误。HTTP 服务器的默认端口是 80，而客户端通常使用操作系统临时分配的动态端口，并非固定使用 80 号端口。

III 正确。浏览器作为客户端，请求服务器上的网页及相关对象，并将服务器返回的内容进行解释和显示。

IV 错误。客户端通常负责主动建立连接和发起请求，但连接建立后，服务器能够向客户端发送响应数据；在支持相应机制的协议版本或应用中，服务器还可主动推送数据。因此“服务器端不能主动发送数据”的绝对表述错误。

所以错误的是 I、II、IV，选择 C。

</details>
